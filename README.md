# Paralympics Dashboard

The Paralympics Dashboard is a data visualization project designed to analyze and present Paralympic Games medal statistics through interactive charts, graphs, and tables. It provides insights into medal distribution across countries, sports, NPCs (National Paralympic Committees), continents, and competition years.

### Key Features
- **Medal Statistics:** Displays total gold, silver, and bronze medal counts.
- **Country-Wise Analysis:** Compares gold medal achievements across participating countries.
- **NPC and Sport Analysis:** Visualizes NPC rankings and sport participation statistics.
- **Sport-Wise Medal Distribution:** Analyzes the percentage contribution of different sports to the overall medal tally.
- **Continental Analysis:** Presents medal distribution across continents using a doughnut chart.
- **Year-Wise Medal Details:** Provides a tabular view of medal statistics by country and competition year.
- **Interactive Filters:** Enables users to explore the data using NPC name and sport code filters.

### Objective
The objective of this project is to transform Paralympic medal data into meaningful visual insights, making it easier to compare country performance, understand medal distribution, and explore trends across sports and competition years.

### Purpose
This dashboard was developed as a learning project to practice data visualization, dashboard design, and interactive reporting using Paralympic Games data.
